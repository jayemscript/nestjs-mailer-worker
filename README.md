# NestJS Mailer Worker

A NestJS email microservice with Gmail and SMTP support, email logs, bulk
sending, application identities, and shareable encrypted SMTP mail accounts.

## Highlights

- Gmail API and GoDaddy SMTP delivery
- Bulk email sending and delivery logs
- User- and system-generated email origins
- Application status controls sending access
- Database mail accounts with encrypted credentials
- Interactive Swagger UI at `http://localhost:7002/docs`
